Chingu Burger 🍔

Sitio web multipágina para una hamburguesería ficticia, desarrollado como proyecto de práctica durante la formación en desarrollo web.

Descripción

Chingu Burger presenta un sitio web con información del negocio, menú de hamburguesas, preguntas frecuentes y medios de contacto.

Tecnologías utilizadas

HTML5

CSS3

Flexbox y CSS Grid

Bootstrap 5.3

Google Fonts

Git y GitHub

Páginas del sitio

Inicio: presentación y galería de hamburguesas.

Nosotros: información sobre la propuesta.

Menú: hamburguesas, descripciones y precios.

Preguntas frecuentes: respuestas a consultas habituales.

Contacto: información para realizar pedidos.
