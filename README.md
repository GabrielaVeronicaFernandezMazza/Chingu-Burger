# Chingu Burger

Sitio web estático multipágina para una hamburguesería ficticia, desarrollado como proyecto final de práctica durante la formación en desarrollo web.

## Descripción

Chingu Burger presenta el negocio, su menú de hamburguesas, información institucional, preguntas frecuentes y medios de contacto.

## Tecnologías utilizadas

- HTML5 y HTML semántico
- CSS3 y Sass (SCSS)
- Bootstrap 5.3
- Flexbox y CSS Grid
- Google Fonts
- AOS para efectos de animación
- Git y GitHub

## Páginas del sitio

- **Inicio:** presentación y hamburguesas destacadas.
- **Nosotros:** información sobre la propuesta del negocio.
- **Menú:** hamburguesas, descripciones y precios.
- **Preguntas frecuentes:** respuestas a consultas habituales.
- **Contacto:** información para realizar pedidos.

## Estructura del proyecto

- index.html: página principal.
- pages/: páginas internas del sitio.
- scss/: estilos organizados en parciales Sass.
- styles/styles.css: hoja de estilos compilada.
- assets/: imágenes utilizadas en el sitio.
- package.json: configuración del proyecto y dependencia de Sass.

## Cómo ejecutar el proyecto

Abrí index.html en un navegador para visualizar el sitio.

Para recompilar los estilos después de modificar el SCSS, ejecutá desde la raíz del proyecto:


npx.cmd sass .\scss\main.scss .\styles\styles.css --no-source-map
